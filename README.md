# SincroAdv — arquivos de atualização

Este repositório guarda apenas os **pacotes de atualização** do SincroAdv, um
sistema interno de uso restrito.

Não há código-fonte aqui.

Os arquivos das releases são baixados e instalados pelo próprio sistema, nas
máquinas onde ele está autorizado a funcionar. Não há nada aqui que sirva a
quem não usa o sistema: sem uma conta autorizada, o programa abre numa tela de
login e não vai além dela.
